# UI Rules

## General

Create a modern developer-tool interface.

The UI should be:

- Clean
- Minimal
- Professional
- Responsive
- Accessible

## Desktop

Display Original and Modified editors side-by-side.

## Mobile

Stack the editors vertically.

## Border Radius

Use a small and consistent border radius.

Prefer:

border-radius: 5px

Avoid excessive rounded/pill-shaped UI.

## Buttons

Buttons must have:

- Clear labels
- Hover state
- Disabled state
- Loading state when necessary

## Editors

Both editors should have:

- Line numbers
- Monospace font
- Scrollable content
- Clear labels
- Good spacing

## Colors

Use clear visual distinction for:

- Added content
- Removed content
- Changed content

Do not rely only on color to communicate meaning.

## Responsive

Test:

- Desktop
- Tablet
- Mobile
