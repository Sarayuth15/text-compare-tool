# Text Compare

## Project Goal

Build a modern web-based Text Compare / Diff Tool.

The application allows users to compare two text inputs and clearly
identify added, removed, and changed content.

## Reference

Use https://text-compare.com/ as a functional and UX reference.

Do not copy its source code, branding, or design exactly.

Create an original modern UI.

## Target Users

Developers, QA engineers, technical users, and general users who need
to compare text.

## Core Features

- Compare two text inputs
- Show line numbers
- Highlight added content
- Highlight removed content
- Highlight changed content
- Clear all
- Switch texts
- Copy result
- Download result
- Ignore whitespace
- Ignore case
- Compare by lines
- Compare by words

## Privacy

Text comparison should happen locally in the browser.

User text must not be sent to a backend server.
